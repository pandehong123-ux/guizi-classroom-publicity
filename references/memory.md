# 长期规范与历史反馈

安装 Skill 时固化的已确认规则：体验与惊喜角度、短句分行、开篇预告/后文展开、每关两图、逐张提示词与文案对应、不制作报名区域、三个智能体、先审核方案且用户确认后制作。

本次用户要求优先。与长期规则冲突时说明具体差异并遵循用户当前选择；当前改动不自动改成长期规则。

## 每次反馈的处理

1. 默认记录在本次任务 `反馈记录.md`：日期、用户原话、涉及位置、如何修改、复核结果。
2. 用户明确“以后都这样”“写进Skill”“长期采用”时，由主控把适用偏好写入下表。原话已明确长期作用域时直接记录，不重复请求确认。
3. 长期条目记录原话、适用范围、日期；替代旧条目时说明生效范围，避免同一规范相互冲突。
4. 文案、视觉、审核三个角色每次启动读取此文件。主控统一维护，子角色不要各自写记忆。
5. 保存本次已确认方案、反馈、审核和成稿供以后查阅；不自动读取所有历史任务，不把新项目内容塞进全局规则。
