## 实际文章结构

开头封面“规资课堂特别篇 / AI小小魔法师 / 暑假嗨起来”。封面后用“魔法大礼包”引出主题；AI角色图与短文案预告三个主要关卡；之后“更刺激的是”预告机器人舞蹈、机械狗，分别配照片；用“我们的AI魔法之旅，现在发车！”进入任务区域。

“本期任务剧透 / AI小小魔法师速集结”后逐项展开：

- 【以诗为墨，神笔绘卷】：短引导 → 神笔情境图 → 输入诗词生成画面的短文案 → 荷塘效果图 → 体验收尾。
- 【化身大圣，火眼金睛】：提问引导 → 孙悟空识别情境图 → 对准神秘二维码与彩蛋短文案 → 学生观察熊猫图 → 侦察/标记/分类收尾。
- 【哪吒降世，代码破关】：角色语气引导 → 哪吒编程情境图 → 亲手编写代码短文案 → 指令挑战图 → 超级指令收尾。
- 【特别关卡，惊喜彩蛋】：一张主题图加短文案，作为该案例附加环节。**用户之后明确规定第二大部分每个关卡配两张图，因此新稿的任何独立关卡均按两图；不要把这张单图例外沿用。**

主要关卡后，再具体介绍机器人舞蹈与机械狗，标题、短文案、实拍图交替。这与开篇预告是有意分工，不删掉后面的展开。

最后时间/地点/对象/二维码/报名规则/关注机构，属于主办方范围，不沿用到新稿。

## 可复用与不可复用

复用：短句分行、对学生说“你”、角色代入、具体操作与惊喜、每关两幅图之间有文字推进、开篇预告后文展开、大图为主。

不可默认复用：AI魔法主题、孙悟空/哪吒角色、机械狗、像素风、扫码功能、实际活动日期人数、报名与“带回家”等承诺。它们是原案内容，需要新课程证据才能使用。
